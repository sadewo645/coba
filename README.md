# Bloomly Studio

Website satu halaman untuk studio florist butik yang menawarkan layanan rangkaian bunga, dekorasi acara, dan langganan korporasi.

## Fitur
- Navigasi sticky dengan dukungan perangkat mobile
- Hero section dengan ajakan bertindak dan statistik bisnis
- Ringkasan layanan, koleksi unggulan, dan testimoni pelanggan
- Formulir kontak cepat untuk konsultasi
- Desain responsif menggunakan kombinasi font Poppins dan Playfair Display

## Cara Menggunakan
Buka `index.html` di peramban favorit Anda atau unggah seluruh folder ke layanan hosting statis.
